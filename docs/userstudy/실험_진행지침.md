# 1. 🔴 왜 10명을 한 번에 앉히면 안 되는가

한 화면을 보면 **모두가 같은 영상을 같은 조건으로** 봅니다. 그러면 1~6번은 항상 B,
7~12번은 항상 A가 되어 **"어떤 클립이 원래 어려운가"와 "조건"이 붙어 버립니다.**

하필 7~12번에 비꼼 두 편이 몰려 있습니다. 7~12번을 A로 고정하면 **A에만 어려운 문제가
가고**, 그래서 나온 격차는 SoundShape 덕분이 아니라 문제 배치 때문입니다. 심사위원이
표를 보면 바로 보입니다.

## 해결 — 5명씩 두 조, 조마다 양식을 뒤집습니다

| | 1~6번 | 7~12번 |
|---|---|---|
| **1조** (D01~D05) · 양식 1 | **B** 자막+SoundShape | **A** 자막만 |
| **2조** (D06~D10) · 양식 2 | **A** 자막만 | **B** 자막+SoundShape |

이러면 클립 하나하나가 두 조건에 고르게 들어가 상쇄됩니다. 참가자는 여전히
**각자 6편 A · 6편 B** 를 보므로 개인 내 비교도 그대로입니다.

# 4. 🔴 화면 — 여기서 실험이 가장 쉽게 망가집니다

우리 시각 언어는 **색상과 채도**로 감정을 나릅니다. 그런데 **프로젝터는 채도를 죽입니다.**
빔으로 쏘면 참가자가 보는 것이 우리가 의도한 색이 아닐 수 있습니다.

| | |
|---|---|
| **가장 좋음** | 큰 **TV·모니터** (HDMI 연결) |
| 차선 | 프로젝터 + **불을 끈 방** |
| 피할 것 | 밝은 방의 프로젝터 |

### 시작 전 반드시

1. **범례를 화면에 띄우고** 맨 뒷자리에 앉아 보십시오
2. **네 가지 색이 서로 다르게 보이는지** 직접 확인하십시오
3. 안 보이면 **불을 더 끄거나 자리를 앞으로 당기십시오**

이게 안 되면 나머지는 의미가 없습니다.

### 자리

- 화면 **정면 부채꼴 안**에 5명. 옆에서 비스듬히 보면 색이 달라집니다
- **서로 응답지가 안 보이게** 간격을 두십시오
- 통역사는 **화면을 가리지 않는 위치**에 서야 합니다

# 7. 한 조 진행

## 0:00 · 착석 · 동의 · 배경 설문 (5분)

응답지를 나눠 주고 **맨 위를 먼저 채우게** 하십시오.

```
1조 → 참가자 D01~D05 · 양식 1
2조 → 참가자 D06~D10 · 양식 2
```

> 코드와 양식을 안 적으면 그 장은 **분석에 못 씁니다.** 나눠 줄 때 미리 적어 두는
> 편이 안전합니다.

동의서는 통역과 함께 읽고 서명받습니다. **민감정보(청력 상태·보조기기)는 별도로**
여쭙고, 동의 안 하셔도 참여 가능하다고 알려 드립니다.

배경 설문: 연령대 / 청력 상태 / 보청기·인공와우 / 주 사용 언어 /
자막으로 감정을 알기 어려웠던 적

## 0:05 · 설명 + 연습 (4분)

1. **범례를 켜고** 통역사를 통해 한 문장:
   > "모양은 어떤 감정인지, 색은 그 감정의 종류, 더 크고 더 많이 움직이면 더 강한 감정입니다."
2. **범례를 끕니다**
3. 응답지 읽는 법 — **한 줄에 하나만**, 오른쪽은 확신도
4. **연습 P1·P2** 를 SoundShape **켠 상태**로 보여 줍니다. 응답지에 적지 않습니다
5. **"모름을 골라도 괜찮습니다"** 를 반드시 말해 주십시오

> 🔴 **정답을 알려 주지 마십시오.**

## 0:09 · 🔴 주 실험 12구간 (11분)

### 반복 (구간당 약 55초)

1. 타임라인에서 **해당 구간**을 누른다
2. **한 번만** 재생한다 (6초)
3. **"○번 표시해 주세요"** — 통역사가 번호를 알려 준다
4. **20초 기다린다.** 다 됐는지 손으로 확인
5. 다음 구간

### 조건 전환 — 한 번뿐입니다

```
1조 :  1~6 = SoundShape 켬   →   7~12 = 끔
2조 :  1~6 = SoundShape 끔   →   7~12 = 켬
```

**6번에서 7번으로 넘어갈 때 토글을 한 번 바꿉니다.**

### 🔴 집단 실시 주의

- **번호를 반드시 불러 주십시오.** 한 사람이 줄을 밀려 적으면 그 장 전체가 날아갑니다
- **가장 느린 사람에 맞추십시오.** 20초가 모자라면 기다리십시오
- **다시 보여 주지 마십시오.** 한 번입니다
- 표정·고갯짓 금지. **통역사에게도 미리 부탁**하십시오
- **3 · 6 · 8 · 9번**에는 진심·비꼼 칸이 있습니다. 그 번호에서는 **"노란 줄도 표시해 주세요"** 라고 알려 주십시오

## 0:20 · 비교 문항 (4분)

### (1) 렌더링 비교 — 3쌍

> 🔴 **자극 SRT 로는 못 합니다.** 하이브리드는 목소리에서 잰 값으로 그리는데
> 스크립트 구간에는 측정값이 없어 두 모드가 같은 그림을 냅니다.
> **6-2 에서 올려 둔 `ko_test.wav` 를 쓰십시오.**

같은 구간을 **하이브리드**와 **AI 전용**으로 번갈아 보여 주고, 어느 쪽이 무엇인지
**알려 주지 않고** 묻습니다.

> "어느 쪽이 목소리의 세기 변화를 더 잘 보여 주나요?" → 첫 번째 / 두 번째 / 모르겠음

순서를 쌍마다 바꾸십시오.

### (2) 화자 전환 대시 — 1문항

2인 대화를 **대시를 켜고** 보여 준 뒤, 설명 없이:

> "화면에서 말하는 사람이 몇 번 바뀌었나요?"
