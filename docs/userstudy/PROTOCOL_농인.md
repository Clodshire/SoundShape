## 3. 블록별 진행

### 3-1. 배경 설문 (3분)

이름은 받지 않습니다. **참가자 코드(D01~D10)** 만 씁니다.

| 항목 | 보기 |
|---|---|
| 연령대 | 10대 / 20대 / 30대 / 40대 / 50대 이상 |
| 청력 상태 | 선천성 / 후천성(시기) |
| **보청기·인공와우** | 사용 안 함 / 보청기 / 인공와우 |
| 주 사용 언어 | 한국수어 / 구화 / 둘 다 |
| 자막으로 **감정**을 알기 어렵다고 느낀 적 | 자주 / 가끔 / 없음 |

*(자막 시청 빈도 항목은 30분 안에 맞추기 위해 뺐습니다. 시간이 남으면 물으십시오.)*

마지막 항목은 **문제 정의 자체를 당사자가 인정하는지**를 묻는 것이라, 결과와 무관하게
보고서 Ⅰ장에 인용할 수 있는 값입니다.

### 3-2. 시각 언어 설명 + 연습 (3분)

**모든 참가자에게 똑같이** 합니다. 이 단계가 사람마다 다르면 실험이 무너집니다.

1. 앱의 **범례(Legend)** 를 켜고 보여 줍니다
2. 통역사를 통해 한 문장씩:
   > "모양은 어떤 감정인지, 색은 그 감정의 종류, 더 크고 더 많이 움직이면 더 강한 감정입니다."
3. **연습 클립 2개** 를 자막+SoundShape 로 보여 주고 답하게 합니다. **채점하지 않습니다.**
   답을 맞혔는지 알려 주지 마십시오 — 학습 효과가 본 실험에 섞입니다.

> ⚠️ **보고서에 반드시 적을 것**: 이 실험은 *설명을 들은 뒤* 의 성능을 잽니다.
> "처음 본 사람도 바로 이해하는가"를 측정하는 것이 **아닙니다.**

### 3-3. 🔴 주 실험 — 12클립 (10분)

#### 두 조건

| | 자막 | SoundShape |
|---|---|---|
| **A** | 켬 | **끔** |
| **B** | 켬 | **켬** |

두 조건 모두 **설정은 기본값**입니다. 개인 맞춤은 아직 하지 않습니다 — 참가자마다 화면이
달라지면 사람 사이 비교가 불가능해집니다.

#### 교차 설계

참가자 한 명이 **12클립을 전부** 보되, **6개는 A, 6개는 B** 로 봅니다. 같은 클립을 두 번
보지 않습니다. 어느 클립이 어느 조건인지는 **양식(form)** 으로 번갈아 바꿉니다.

| 양식 | 클립 1–6 | 클립 7–12 |
|---|---|---|
| **양식 1** | **B** | A |
| **양식 2** | A | **B** |

**D01→양식1, D02→양식2, D03→양식1 …** 번갈아 배정합니다. 이렇게 하면 "어떤 클립은 원래
쉽다"는 차이가 두 조건에 고르게 퍼져 상쇄됩니다.

#### 클립 구성 (12개) — 촬영 대본은 `클립_촬영대본.md`

| 개수 | 종류 |
|---|---|
| 7 | 말과 감정이 어긋나지 않는 발화 |
| 3 | **비꼼·억눌린 감정** (`incongruent=yes`) — 0%→67% 가 나온 지점 |
| 2 | **배경 음악이 깔린 발화** (`music=yes`) — 음원 분리 확인 |

> 🔴 **12편 모두 서로 다른 녹음이고, 한 참가자가 같은 문장을 두 번 보지 않습니다.**
> 같은 영상을 두 번 보여 주면 두 번째는 화면이 아니라 **기억**을 재게 됩니다.
> 3클립×4변형, 4클립×3변형 같은 구성을 쓸 수 없는 이유입니다.
>
> 대신 **12문장 전부를 글자만으로는 감정을 알 수 없게** 골랐습니다(`"다 끝났어."`가
> 홀가분한 것인지 무너지는 것인지 글자로는 알 수 없습니다). 반복 없이도 같은 효과를
> 냅니다 — A조건에서 참가자는 **원리적으로 맞힐 수 없고**, 그래서 낮은 정답률을
> "운율이 없어서"라고 인과적으로 말할 수 있습니다.

정답 감정은 **제3자 3인의 청취 일치(2/3 이상)** 로 확정합니다. "슬프게 연기했으니
정답은 슬픔"은 근거가 아닙니다. 절차는 촬영 대본 4절에 있습니다.

⚠️ 공포·놀람이 각 1편뿐이라 **감정별 정확도는 보고하지 마십시오.** 전체 정확도만 씁니다.

화자 전환 문항(3-5)에는 **본 실험에 없는 별도 클립(S1)** 을 씁니다.

#### 클립마다 묻는 것

1. **감정** — 6지선다: 기쁨 / 슬픔 / 분노 / 공포 / 놀람 / 중립
2. **말투** — `incongruent=yes` 클립에서만: 진심 / 비꼼
3. **확신도** — 1(찍었다) ~ 5(확실하다)

한 클립당 **한 번만** 재생합니다. 다시 보여 달라고 해도 다시 보여 주지 마십시오.

기록 형식 (`responses.csv`):

```
participant_id,form,clip_id,condition,chosen_emotion,tone,confidence
D01,1,1,B,sad,,4
```

> 🔴 **진행자가 절대 하면 안 되는 것**: 표정·고갯짓·"음…" 같은 반응. 정답을 알려 주는
> 신호가 됩니다. 통역사에게도 미리 부탁하십시오 — 통역사가 무심코 힌트를 줄 수 있습니다.

### 3-4. 개인 맞춤 설정 (5분) — 줄이지 마십시오

`http://localhost:3000/study` 를 열고 참가자가 직접 합니다. 40문항, 약 5분.

이 검사 안에 **크로스오버 블록**이 들어 있습니다: 같은 감정을 **기본 설정**과 **그 사람의
설정**으로 각각 보여 주되, 어느 쪽인지 알려 주지 않고 섞어서 냅니다. 참가자가 어느 쪽이
자기 설정인지 모르므로 기대가 결과를 만들지 못합니다.

> 개인화가 효과가 있다는 주장은 "정확도가 올랐다"로는 증명되지 않습니다. 학습 유형(learning
> styles) 연구가 바로 그 근거를 내놓았다가 제대로 된 검증에서 무너졌습니다(Pashler et al. 2008).
> 필요한 것은 **교차 상호작용** — 그 사람에게 맞춘 설정이 맞지 않는 설정보다 나아야 하고,
> 프로필이 다른 사람에게서는 방향이 달라야 합니다. 이 블록이 그 구조입니다.

**참가자 구분** 칸에는 `D01` 처럼 참가자 코드를 넣으십시오.

### 3-5. 비교 문항 (3분)

#### (1) 측정 기반 vs AI 전용 — 3쌍

같은 클립을 두 방식으로 나란히 보여 주고 묻습니다. 어느 쪽이 무엇인지 **알려 주지 않습니다.**

> "어느 쪽이 **목소리의 세기 변화**를 더 잘 보여 주나요?" → 왼쪽 / 오른쪽 / 모르겠음

좌우 위치는 쌍마다 무작위로 바꾸십시오.

#### (2) 화자 전환 대시 — 1문항

2인 대화 클립을 **대시 표기를 켜고** 보여 줍니다. 설명 없이:

> "화면에서 말하는 사람이 몇 번 바뀌었나요?"

> ⚠️ **이 문항이 재는 것은 표기의 이해도이지 검출 정확도가 아닙니다.** 검출은 이미
> VoxConverse 로 쟀고 정밀도 74%로 기준 미달이라 평소에는 꺼 둡니다. 이 문항에는
> **대시 위치를 사람이 미리 확인한 클립**만 쓰십시오. 그래야 "표기가 이해되는가"만
> 남습니다.

### 3-6. 자유 사용 (2분)

참가자가 직접 아무 영상이나 올려 보게 합니다. 이때 **되묻기 카드**(저확신 구간에서 뜨는
질문)가 나오면 답하게 하십시오.

> 💡 이 2분이 실제 문제 하나를 해결합니다. 되묻기 루프는 **지금까지 응답이 0건**이라
> 보고서에 실험으로 쓸 수 없는 상태입니다. 10명에게서 응답을 모으면 기능이 살아납니다.

### 3-7. 설문 + 인터뷰 (4분)

| 문항 | 형식 |
|---|---|
| SoundShape 가 감정을 아는 데 도움이 됐다 | 1~7 |
| **화면을 가려서 불편했다** | 1~7 |
| 자막을 읽으면서 동시에 보기 어려웠다 | 1~7 |
| 실제로 쓰고 싶다 | 1~7 |
| 어디에 쓰고 싶은가 | 드라마·영화 / 뉴스 / 영상통화 / 강의 / 유튜브 (복수) |

**"화면을 가려서 불편했다"** 를 반드시 넣으십시오. 이 값이 높게 나오면 그것 자체가 중요한
발견이고, 숨기면 심사위원이 먼저 묻습니다.

인터뷰 2문항 (자유 응답, 통역사 통해):

2. 하나만 바꿀 수 있다면 무엇을 바꾸겠습니까?

## 4. 분석 계획 — 실험 전에 정해 둡니다

**나중에 정하면 좋은 결과만 고른 것이 됩니다.** 아래를 먼저 확정하십시오.

### 주 결과 (이것 하나가 헤드라인)

참가자별로 A 정확도와 B 정확도를 내고, 그 **차이에 대응표본 t검정**을 합니다.
기존 스크립트가 그대로 돌아갑니다:

```bash
~/.soundshape_venv/bin/python scripts/analyze_userstudy.py
```

n=10 이라 정규성을 확인할 수 없으므로 **윌콕슨 부호순위 검정도 같이** 보고하십시오.
두 검정의 결론이 같으면 결과가 튼튼하다는 뜻입니다.

효과 크기(Cohen's dz)도 함께 적으십시오. p값만으로는 "얼마나 큰가"를 말할 수 없습니다.

### 부 결과 (탐색적이라고 명시)

| 항목 | 표본 | 어떻게 쓰나 |
|---|---|---|
| 비꼼·억눌린 감정 | 3클립 | **기술 통계만.** 검정하기엔 너무 적습니다 |
| 음악 있는 클립 | 2클립 | 기술 통계만 |
| 렌더링 비교 | 30쌍 | 이항검정 가능 |
| 캘리브레이션 크로스오버 | 10인 | 내장 분석 |

> 🔴 **부 결과에 p값을 붙여 주장하지 마십시오.** 클립 3개로 검정하면 우연이 유의하게
> 나옵니다. "기존 6인 실험과 같은 방향이었다" 정도가 정직한 서술입니다.

### n=10 으로 말할 수 있는 것과 없는 것

| 말할 수 있다 | 말할 수 없다 |
|---|---|
| 큰 효과(기존 +46%p 수준)가 당사자에게도 나타나는가 | 작은 차이 |
