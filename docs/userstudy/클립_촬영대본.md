# 실험 클립 촬영 대본 (12편 + 연습 2편 + 대시용 1편)

> 반나절이면 끝납니다. **연기를 잘할 필요는 없습니다** — 뒤의 검증 단계에서
> 전달이 안 된 클립은 버리고 다시 찍으면 됩니다.

---

## 1. 왜 이 문장들인가

모든 문장이 **글자만 봐서는 감정을 알 수 없게** 골랐습니다. 이것이 실험의 핵심입니다.

자막만 보는 조건(A)에서 참가자는 `"다 끝났어."` 라는 글자를 봅니다. 이게 홀가분한 것인지
무너지는 것인지 **글자로는 알 방법이 없습니다.** 그래서 A조건의 낮은 정답률을
"운율 정보가 없어서"라고 **인과적으로** 말할 수 있습니다.

문장이 감정을 흘리면(예: "너무 슬퍼") 자막만으로도 맞힐 수 있어 실험이 무너집니다.

> 🔴 **한 참가자가 같은 문장을 두 번 보면 안 됩니다.** 두 번째는 화면이 아니라 기억을
> 재게 됩니다. 그래서 12편 전부 문장이 다릅니다.

---

## 2. 촬영 목록

**길이 5~15초.** 말은 짧고, 앞뒤로 1초쯤 여유를 둡니다.

### 연습용 (채점하지 않음)

| # | 문장 | 목표 감정 |
|---|---|---|
| P1 | 내일 소풍 간대. | 기쁨 |
| P2 | 이제 못 봐. | 슬픔 |

### 본 실험 — 말과 감정이 어긋나지 않는 것

| # | 문장 | 목표 감정 | 연기 지시 |
|---|---|---|---|
| 1 | 이제 안 와. | **슬픔** | 말끝을 흐리고 숨이 가라앉게 |
| 2 | 지금 뭐라고 했어. | **분노** | 낮고 단단하게, 끝을 내리누르며 |
| 3 | 내일 만나기로 했어. | **기쁨** | 음이 올라가고 빨라지게 |
| 4 | 저기 누가 있어. | **공포** | 숨을 죽이고 떨리게, 작게 |
| 5 | 벌써 왔어? | **놀람** | 첫 음을 확 올리고 끊어서 |
| 6 | 여덟 시에 시작해. | **중립** | 사무적으로. 아무 색도 넣지 말 것 |
| 12 | 책상 위에 뒀어. | **중립** | 사무적으로 |

### 본 실험 — 말과 감정이 어긋나는 것 🔴 이 작품의 핵심

| # | 문장 | 목표 감정 | 연기 지시 |
|---|---|---|---|
| 7 | 난 괜찮아. | **슬픔** | 괜찮은 척하다 목소리가 무너지게 |
| 8 | 아주 잘했네. | **분노** | 칭찬하는 말을 이 악물고 |
| 9 | 정말 고마워. | **분노** | 고맙다는 말을 차갑게 내뱉듯 |

> 이 세 편이 **자막만으로는 정반대로 읽히는** 클립입니다. 기존 6인 실험에서
> 0% → 67% 가 나온 지점이 여기입니다.

### 본 실험 — 배경 음악이 깔린 것

| # | 문장 | 목표 감정 | 음악 |
|---|---|---|---|
| 10 | 다 끝났어. | **슬픔** | 대사와 비슷한 크기로 깔 것 |
| 11 | 알았다고. | **분노** | 대사와 비슷한 크기로 깔 것 |

음악은 **저작권 없는 것**을 쓰십시오. 목소리를 덮을 만큼 크게 깔아야 음원 분리가
할 일이 생깁니다. 너무 작으면 분리 기능이 켜지지도 않습니다(음악 에너지 비율 0.45 기준).

### 화자 전환 문항용 (본 실험 12편에 포함하지 않음)

| # | 내용 |
|---|---|
| S1 | **두 사람이 번갈아 4번** 주고받는 대화 (약 15초). 목소리 차이가 뚜렷한 두 사람 |

> 본 실험에 넣지 않는 이유: 같은 영상을 감정 문항에서도 쓰고 대시 문항에서도 쓰면
> 그 참가자에게는 두 번 보이는 셈이 됩니다.

### 감정 분포

| 감정 | 편수 |
|---|---|
| 슬픔 | 3 (1, 7, 10) |
| 분노 | 3 (2, 8, 9, 11 중 3편) |
| 기쁨 | 1 (3) |
| 공포 | 1 (4) |
| 놀람 | 1 (5) |
| 중립 | 2 (6, 12) |

완전히 균등하지는 않습니다. **불일치 클립과 음악 클립을 넣느라 그렇습니다.**
정답률은 클립별로 평균 내므로 분석에는 문제가 없지만, 공포·놀람이 1편뿐이라
**감정별 정확도는 보고하지 마십시오.** 전체 정확도만 씁니다.

## 3. 촬영 방법

| | |
|---|---|
| 화자 | **2~3명** (남녀 섞을 것). 한 사람이 12편을 다 하면 그 사람 목소리를 시험하는 셈이 됩니다 |
| 화면 | 상반신. **입이 보이게** — 구화를 쓰는 참가자가 있습니다 |
| 배경 | 단순하게. 시각 표현이 배경과 겹치면 안 됩니다 |
| 소리 | 조용한 방. 에어컨·선풍기 끄기 |
| 촬영 | 휴대폰이면 충분합니다. **가로로** 찍으십시오 |
| 형식 | `.mp4`. 편당 5~15초로 잘라 `data/study_clips/01.mp4` … 로 저장 |

> 🔴 **한 문장을 3번씩 찍으십시오.** 검증에서 떨어지는 클립이 반드시 나옵니다.
> 다시 모으는 것보다 그 자리에서 여러 번 찍는 편이 훨씬 쌉니다.

## 4. 🔴 검증 — 이 단계를 빼면 정답지가 근거를 잃습니다

"내가 슬프게 연기했으니 정답은 슬픔"은 근거가 아닙니다. **연기가 전달됐는지**를
따로 확인해야 합니다.

1. **들을 수 있는 사람 3명** 을 모읍니다 (실험 참가자가 아닌 사람).
2. 화면 없이 **소리만** 들려줍니다. 자막도 보여 주지 않습니다.
3. 6지선다로 감정을 고르게 합니다.
4. **3명 중 2명 이상이 목표 감정을 고른 클립만 채택**합니다.
5. 떨어진 클립은 다른 테이크로 교체하고 다시 검증합니다.

이 절차 덕분에 보고서에 이렇게 쓸 수 있습니다:

> "각 클립의 정답 감정은 제3자 3인의 청취 일치(2/3 이상)로 확정하였다."

연기 지시대로 찍었는데 2/3을 못 넘으면 **그 감정은 목소리만으로는 전달되기 어렵다**는
뜻입니다. 그것도 결과입니다 — 억지로 채택하지 말고 기록해 두십시오.

## 5. 파이프라인 확인

채택한 클립을 전부 한 번씩 돌려 보십시오. 자막이 깨지거나 분리가 엉뚱하게 켜지는
클립은 **실험 당일이 아니라 지금** 발견해야 합니다.

```bash
~/.soundshape_venv/bin/python -c "
from backend.pipeline.timeline import build_timeline
import glob, json
for f in sorted(glob.glob('data/study_clips/*.mp4')):
    tl = build_timeline(f)
    segs = tl['segments'] if isinstance(tl, dict) else tl
    print(f, '| 구간', len(segs), '|', ' / '.join(s['text'][:18] for s in segs[:2]))
"
```

확인할 것: **자막 글자가 맞는가**(Whisper가 잘못 들으면 A조건이 무의미해집니다),
구간이 하나로 잡히는가, 음악 클립에서 분리가 켜지는가.
