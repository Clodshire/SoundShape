# Ⅲ. 작품 테스트

이 시스템은 음성에서 감정을 추출해 시각으로 번역한다는 점에서 기존 자막과 근본적으로 다르다. 따라서 *"안정적으로 작동하는가 → 감정을 정확히 읽는가 → 실제로 사용자에게 도움이 되는가"* 를 단계적으로 검증해야 한다. 그 중 가장 중요한 **세 가지**를 테스트한다.

&nbsp;&nbsp;**A.** 시스템 안정성(자동화 테스트)
&nbsp;&nbsp;**B.** 감정 인식 정확도
&nbsp;&nbsp;**C.** 자막+SoundShape의 감정 이해 향상 효과(사용자 실험)

따라서 위 세 가지를 각각 테스트하여 시스템의 안정성·정확도·실효성을 평가하고 개선점을 찾는다.

---

## A. 시스템 안정성 테스트

### 1. 테스트 목적: 시스템 안정성
실제 발표 시연이나 사용 중에는 **무음 구간, 손상된 파일, 잘못된 입력** 등 예기치 못한 상황이 발생한다. 이때 시스템이 멈추거나 오작동하면 신뢰성을 잃는다. 따라서 핵심 로직(감정→시각 매핑 등)이 의도대로 동작하는지, 그리고 비정상 입력에도 **충돌 없이** 처리되는지를 자동으로 검증한다.

### 2. 테스트 방법: 시스템 안정성

**2.1 사용 도구**

| 도구 | 도구의 활용법 |
|---|---|
| pytest (Python) | 명령어 한 줄로 23개 자동화 테스트를 일괄 실행한다. |
| 맥북 에어 | 백엔드 소스코드와 테스트를 실행하는 개발 환경이다. |
| 합성 입력 데이터 | 코드로 **무음 음성**과 **손상된(음성이 아닌) 파일**을 생성해 실패 상황을 인위적으로 만든다. |

**2.2 단계별 테스트 방법**
1) 매핑 정확성·감정/운율 로직·실패 케이스의 세 종류로 **총 23개**의 테스트를 작성한다.
2) 코드로 무음 파일·손상 파일·잘못된 시간 구간을 생성한다.
3) 터미널에서 `pytest`를 실행한다.
4) 각 테스트의 통과 여부와, 비정상 입력에서 **프로그램이 멈추지 않는지(충돌 여부)**를 확인한다.
5) 백엔드(Python)와 프론트엔드(TypeScript)의 매핑 결과가 **동일**한지 별도로 대조한다.

### 3. 예상 결과: 시스템 안정성
핵심 로직은 모두 정상 동작하여 테스트가 **전부 통과**하고, 무음·손상·경계 입력에도 시스템이 **멈추지 않고** 안전하게 처리할 것이다.

### 4. 실제 결과: 시스템 안정성

| 테스트 분류 | 개수 | 통과 | 비고 |
|---|---|---|---|
| 매핑 정확성(연구 규칙·Python/TS 동일성) | 7 | 7 | 분노=빨강·각진·떨림 등 규칙 일치 |
| 감정·운율 로직(보정·하이브리드·운율 변조) | 6 | 6 | — |
| 음성 분할(침묵 기준 청크) | 3 | 3 | — |
| 데이터 파싱(라벨 해석) | 3 | 3 | — |
| 오디오 입출력·**실패 케이스** | 4 | 4 | 무음·손상 파일·잘못된 구간 무충돌 |
| **합계** | **23** | **23** | **약 8초, 충돌 0건** |

### 5. 결과 분석: 시스템 안정성
예상대로 **23개 전부 통과**했고, 무음·손상·경계 입력 모두 **충돌 없이** 처리되었다. 특히 실패 케이스의 무중단을 확인하여 시연 중 돌발 입력에도 안전함을 입증했고, 백엔드·프론트엔드 매핑이 동일함을 검증하여 두 실행 환경의 일관성을 확보했다. 즉, 시스템의 **소프트웨어 품질과 견고성**이 확인되었다.

## B. 감정 인식 정확도 테스트

### 1. 테스트 목적: 감정 인식 정확도
*"음성의 감정을 시각화한다"*는 본 작품의 주장이 성립하려면, 그 전제인 **감정 인식이 실제로 정확**해야 한다. 따라서 주 사용 언어인 **한국어**와 비교 기준인 **영어** 두 언어에서 감정 인식 정확도를 객관적 데이터로 측정한다.

### 2. 테스트 방법: 감정 인식 정확도

**2.1 사용 도구**

| 도구 | 도구의 활용법 |
|---|---|
| RAVDESS (영어) [1] | 배우가 8가지 감정을 연기한 음성으로, 정답 라벨이 있어 정확도 측정에 사용한다. |
| AIHub「감정 분류를 위한 대화 음성」(한국어) [2] | 자연스러운 대화 음성을, 평가자 **5인의 다수결**로 7가지 감정으로 라벨링한 데이터다. |
| Parselmouth(PRAAT) | 음높이·세기·지터·시머 등 **운율 특징**을 추출한다. |
| wav2vec2 | 음성에서 감정 **임베딩**을 추출한다. |
| scikit-learn | 분류기 학습·교차검증·정확도/혼동행렬 계산에 사용한다. |

**2.2 단계별 테스트 방법**
1) 두 데이터셋을 준비한다(한국어는 평가자 5인 다수결로 최종 감정 라벨을 정한다).
2) **제로샷:** 배포된 시스템(영어로 학습된 기성 모델)을 *그대로* 적용해 각 음성의 감정을 예측하고 정답과 비교한다.
3) **학습형:** 각 음성에서 wav2vec2 임베딩과 PRAAT 운율 특징을 추출해 하나의 특징으로 결합한다.
4) 결합한 특징으로 분류기(SVM)를 **학습**하고, *처음 듣는 목소리*로 평가하기 위해 영어는 **화자독립 교차검증**, 한국어는 층화 교차검증으로 측정한다.
5) 정확도·F1·혼동행렬, 그리고 운율–정답 상관(각성·정서가)을 계산한다.

### 3. 예상 결과: 감정 인식 정확도
기성 모델은 언어·도메인 차이로 완벽하지 않을 것이며, 운율은 *각성(흥분도)* 축에 강할 것이다. **한국어가 영어보다 낮고, 학습형이 제로샷보다 높을 것**이다.

### 4. 실제 결과: 감정 인식 정확도

| 언어 / 데이터 | 제로샷(기성 모델) | 학습형 분류기 |
|---|---|---|
| **영어** (RAVDESS, 연기 음성) | **55.0 %** (4분류) | **79.8 %** (4분류, 화자독립) / 74.2 %(8분류) |
| **한국어** (AIHub, 자연 대화) | **17.5 %** (7분류, 우연=14.3 %) | **43.6 %** (7분류) |

- 영어 운율–정답 상관: **각성 r = 0.73 (강함)**, **정서가 r = 0.42 (약함)**
- 학습은 **두 언어 모두 약 +25점** 향상(영어 +25, 한국어 +26)
- 가장 잘 맞춘 감정: 영어=분노(F1 0.87), 한국어=공포(F1 0.55) — 모두 **고각성 감정**

### 5. 결과 분석: 감정 인식 정확도
첫째, **한국어 제로샷 17.5 %는 우연(14.3 %)과 거의 같다.** 즉 영어로 학습된 기성 모델은 한국어 자연발화에 *사실상 무력*하며, 이는 우리가 한계로 *추정*하던 것을 **숫자로 입증**한 결과다. 둘째, **학습이 두 언어 모두 +25점**을 더해, 본 접근법이 특정 언어에 종속되지 않고 **일반화**됨을 보였다. 셋째, **각성은 신뢰할 수 있으나(0.73) 정서가는 음향만으로 어렵다(0.42).** 이는 음성 감정 인식 분야 전반의 *'정서가 문제'*로, 우리가 텍스트 보조·보정을 도입한 이유와 일치한다. 또한 **시각의 핵심(크기·채도·움직임)이 신뢰 가능한 각성에 의존**하므로, 한국어에서도 시각이 전달하는 감정 정보는 유지된다.

## C. 감정 이해 향상 효과 테스트 (사용자 실험)

### 1. 테스트 목적: 감정 이해 향상 효과
본 작품의 존재 이유는 *"청각장애인이 감정을 더 잘 이해하게 한다"*이다. 따라서 **소리를 끈 상태**(청각장애 상황 모사)에서 **자막만** 볼 때와 **자막+SoundShape**를 볼 때의 **감정 인식 정확도를 직접 비교**하여, 작품이 실제로 효과가 있는지 검증한다.

### 2. 테스트 방법: 감정 이해 향상 효과

**2.1 사용 도구**

| 도구 | 도구의 활용법 |
|---|---|
| SoundShape 웹앱 | *SoundShape ON/OFF·자막 ON/OFF* 토글로 두 조건을 같은 화면에서 전환한다. |
| 감정 클립 8개 | 정답 감정이 정해진 짧은 영상. 일부는 **비꼼·억눌린 감정**(말과 뜻이 다른 경우)을 포함한다. |
| 참가자 6인 | 소리를 끄고 시청하는 정상 청각자는 청각장애 상황의 **인정된 대체 실험 방식**이다. |
| 분석 스크립트(Python) | 응답을 정답과 비교해 조건별 정확도와 **대응표본 t검정**을 자동 계산한다. |

**2.2 단계별 테스트 방법**
1) 8개 클립과 각 클립의 **정답 감정(answer key)**을 준비한다.
2) 참가자마다 클립–조건 배정을 **form으로 교차 균형**해, 같은 클립이 두 조건에 고르게 배정되도록 한다(클립 난이도 편향 제거).
3) **소리를 끈 상태**로, 각 클립을 조건 **A(자막만)** 또는 **B(자막+SoundShape)**로 한 번씩 보여 준다.
4) 각 클립 직후 **감정 6지선다**(기쁨/슬픔/분노/공포/놀람/중립)와 **확신도(1~5)**를 응답받아 기록한다.
5) 분석 스크립트로 조건별 정확도를 집계하고, 대응표본 t검정으로 유의성을 검증한다.

### 3. 예상 결과: 감정 이해 향상 효과
자막+SoundShape(B)가 자막만(A)보다 감정 정확도가 **높을 것**이며, **특히 비꼼·억눌린 감정에서 차이가 클 것**이다.

### 4. 실제 결과: 감정 이해 향상 효과 (소리 끔, 참가자 6인)

| 조건 | 감정 인식 정확도 |
|---|---|
| A. 자막만 | **27 %** |
| B. 자막 + SoundShape | **73 %** |
| **향상폭** | **+45 %p** |

- 대응표본 t검정 **p = 0.016 → 통계적으로 유의 (p < 0.05)**
- **비꼼·억눌린 감정 클립: 0 % → 67 %**
- 평균 확신도: 3.3 → 3.5

### 5. 결과 분석: 감정 이해 향상 효과
예상대로 자막+SoundShape가 우세했으며, 그 **효과 크기가 매우 컸다(+45 %p).** 특히 **비꼼·억눌린 감정에서 0 % → 67 %**의 향상은, 자막만으로는 *아무도* 비꼼을 읽지 못했지만 SoundShape를 더하자 다수가 정확히 읽었음을 뜻한다. 이는 *"말투가 글자를 이긴다"*는 본 작품의 핵심 가설을 **직접 입증**하며, 결과가 **통계적으로 유의(p=0.016)**하여 우연이 아님을 보였다. 다만 표본이 6인으로 적고, 정상 청각자의 무음 실험이며, 같은 클립을 두 조건에서 본 설계라는 한계가 있다. 이는 추후 **청각장애인 당사자 및 대규모 표본**으로 보완할 부분이다.
