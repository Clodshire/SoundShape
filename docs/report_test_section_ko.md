# Ⅲ. 작품 테스트

본 작품은 **세 가지 테스트**로 검증하였다. 각 테스트는 *"고장 나지 않는가(A) → 맞는가(B) → 쓸모 있는가(C)"* 의 순서로, 작품의 신뢰성을 단계적으로 입증한다. 아래에 **각 테스트마다 5개 항목**(목적·방법·예상·실제·분석)을 기술한다.

---

## ◆ 테스트 A — 시스템 안정성 테스트

### 1. 테스트 목적
실제 발표 시연이나 사용 중에 **예기치 못한 입력(무음 구간, 손상된 파일 등)이 들어와도 시스템이 멈추지 않아야** 하며, 핵심 로직(감정→시각 매핑 등)이 **의도대로 정확히 동작**함을 자동으로 보장하기 위함이다.

### 2. 테스트 방법
- **주체:** 개발자 본인이 작성한 자동화 테스트.
- **대상:** 시스템 내부 코드 — 매핑 엔진, 운율·감정·음성분할 로직, 파일 처리 모듈.
- **도구·활용법:** 파이썬 표준 테스트 도구 **`pytest`**. 명령어 한 줄(`pytest`)로 **23개 테스트를 일괄 실행**한다.
- **방법:** 세 종류의 테스트를 작성하였다.
  1. **정확성 테스트** — 감정→시각 매핑이 연구 규칙대로 동작하는가(예: 분노=빨강·각진 형태·떨림), **백엔드(Python)와 프론트엔드(TypeScript)의 매핑 결과가 동일**한가.
  2. **로직 테스트** — 운율 추출·음성 분할·감정 보정 로직이 올바른가.
  3. **실패 케이스 테스트** — **무음 파일, 손상된(음성이 아닌) 파일, 잘못된 시간 구간** 등 비정상 입력에서 시스템이 **충돌 없이** 처리되는가.

### 3. 예상 결과
모든 테스트가 통과하고, 비정상 입력에도 시스템이 **무중단**으로 안전하게 처리할 것.

### 4. 실제 결과
- 자동화 테스트 **23개 전부 통과**(약 8초 소요).
- **무음 파일·손상 파일·경계 입력 모두 정상 처리되며, 충돌이 발생하지 않음.**

### 5. 결과 분석
**예상대로 전부 통과**하였다. 특히 *실패 케이스에서의 무중단*을 확인함으로써 시연 중 돌발 입력에도 시스템이 안전함을 입증했고, **백엔드·프론트엔드 매핑의 동일성 검증**으로 두 실행 환경의 일관성을 보장했다 → **소프트웨어 품질·견고성 확보.**

---

## ◆ 테스트 B — 감정 인식 정확도 테스트

### 1. 테스트 목적
*"음성의 감정을 시각화한다"*는 주장이 성립하려면, 그 전제인 **감정 인식이 실제로 정확**해야 한다. 이를 **영어·한국어 두 언어**에서 객관적 데이터로 측정한다.

### 2. 테스트 방법
- **주체:** 개발자 본인.
- **대상 데이터:**
  - **영어:** RAVDESS — 전문 배우가 8가지 감정을 연기한 음성(정답 라벨 포함, 깨끗함).
  - **한국어:** AIHub *'감정 분류를 위한 대화 음성 데이터셋'* — **자연스러운 대화 음성**에 평가자 **5인의 다수결**로 7가지 감정 라벨을 부여한 데이터.
- **도구·활용법:** Praat/Parselmouth(운율 추출), wav2vec2(감정 임베딩), scikit-learn(분류기·평가 지표·혼동행렬).
- **방법(두 조건으로 측정):**
  1. **제로샷(zero-shot):** 별도 학습 없이 **배포된 시스템 그대로**(영어로 학습된 기성 모델) 적용 → *"있는 그대로 쓰면 얼마나 되는가"*.
  2. **학습형(trained):** wav2vec2 임베딩 + PRAAT 운율 특징을 결합해 분류기(SVM)를 학습. 영어는 **화자독립 교차검증**(평가 화자를 학습에서 완전히 제외 → 처음 듣는 목소리로 시험), 한국어는 층화 교차검증.

### 3. 예상 결과
기성 모델은 언어·도메인 차이로 완벽하지 않을 것이며, 운율은 *각성(흥분도)* 축에 강할 것이다. **한국어가 영어보다 낮고, 학습형이 제로샷보다 높을 것.**

### 4. 실제 결과
**① 정확도 종합**

| | 제로샷(기성 모델) | 학습형 분류기 |
|---|---|---|
| **영어**(RAVDESS, 연기) | **55.0%** (4분류) | **79.8%** (4분류, 화자독립) / 74.2%(8분류) |
| **한국어**(AIHub, 자연 대화) | **17.5%** (7분류, 우연=14.3%) | **43.6%** (7분류) |

**② 세부 지표**
- 영어 운율–정답 상관: **각성 r = 0.73(강함)**, **정서가 r = 0.42(약함)**.
- 학습은 **두 언어 모두 약 +25점** 향상(영어 +25, 한국어 +26).
- 가장 잘 맞춘 감정: 영어=분노(F1 0.87), 한국어=공포(F1 0.55) — 모두 **고각성 감정**.

### 5. 결과 분석
**예상이 적중했고, 그 이상을 정량적으로 밝혔다.**
1. **한국어 제로샷 17.5%는 우연(14.3%)과 거의 같다.** 즉 영어로 학습된 기성 모델은 한국어 자연발화에 *사실상 무력*하다 — 우리가 한계로 *추정*하던 것을 **숫자로 입증**했다(정직성).
2. **학습이 두 언어 모두 +25점**을 더했다 → 본 접근법이 **특정 언어에 종속되지 않고 일반화**됨을 보였다.
3. **각성은 신뢰(0.73), 정서가는 음향만으로 어렵다(0.42).** 이는 음성 감정 인식 분야의 알려진 *'정서가 문제'*로, 우리가 **텍스트 보조·보정**을 도입한 이유와 정확히 일치한다. 또한 **시각의 핵심(크기·채도·움직임)이 신뢰 가능한 각성에 의존**하므로, 한국어에서도 시각이 전달하는 감정 정보는 유지된다.

## ◆ 테스트 C — 사용자 효과 테스트 (핵심)

### 1. 테스트 목적
본 작품의 존재 이유는 *"청각장애인이 감정을 더 잘 이해하게 한다"*이다. 따라서 **소리를 끈 상태**에서 **자막만** 볼 때와 **자막+SoundShape**를 볼 때의 **감정 인식 정확도를 직접 비교**하여, 작품의 실제 효과를 검증한다.

### 2. 테스트 방법
- **주체:** 개발자가 진행.
- **대상:** **참가자 6인**(가족 등). *소리를 끄고 보는 정상 청각자*는 청각장애 상황의 **인정된 대체 실험 방식**이다.
- **도구·활용법:** 본 작품 **웹앱**의 *SoundShape ON/OFF·자막 ON/OFF 토글* 기능과 결과 **분석 스크립트**.
- **방법(통제된 비교 실험):**
  - **소리를 끈 상태**로 **8개 클립**을 시청. 절반은 **조건 A(자막만)**, 절반은 **조건 B(자막+SoundShape)**.
  - 클립–조건 배정을 **form으로 교차 균형(counterbalanced)** → 같은 클립이 두 조건에 고르게 배정되어 *"어떤 클립이 원래 쉽다"*는 편향을 상쇄.
  - 각 클립 직후 **감정 6지선다**(기쁨/슬픔/분노/공포/놀람/중립)와 **확신도(1~5)**를 응답.
  - 정답 대비 정확도를 조건별로 집계하고, **대응표본 t검정(paired t-test)**으로 유의성 검증.

### 3. 예상 결과
자막+SoundShape(B)가 자막만(A)보다 감정 정확도가 **높을 것**이며, **특히 비꼼·억눌린 감정에서 차이가 클 것**.

### 4. 실제 결과 (소리 끔, N=6)

| 조건 | 감정 인식 정확도 |
|---|---|
| 자막만 (A) | **27%** |
| 자막 + SoundShape (B) | **73%** |
| **향상폭** | **+45%p** |

- 대응표본 t검정 **p = 0.016 → 통계적으로 유의(p < 0.05)**.
- **비꼼·억눌린 감정 클립: 0% → 67%**.
- 평균 확신도: **3.3 → 3.5**.

### 5. 결과 분석
**예상대로 자막+SoundShape가 우세했고, 효과 크기가 매우 컸다(+45%p).**
- 특히 **비꼼·억눌린 감정에서 0% → 67%**의 향상은, *"말투가 글자를 이긴다"*는 본 작품의 핵심 가설을 **직접 입증**한다. 자막만으로는 아무도 비꼼을 읽지 못했지만, SoundShape를 더하자 다수가 정확히 읽었다.
- 결과는 **통계적으로 유의(p=0.016)**하여 이 향상이 우연이 아님을 보였다.
- **정직한 한계:** 표본이 6인으로 적고, 정상 청각자의 무음 실험이며, 같은 클립을 두 조건에서 본 설계라는 점을 명시한다. 추후 *청각장애인 당사자·대규모 표본*으로 보완할 부분이다.
