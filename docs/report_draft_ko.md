# SoundShape — 음성의 감정을 시각 언어로 번역하는 감정 자막 시스템
### 작품설명서 (서식 2)

> ※ [n] 으로 표기된 통계·인용은 설명서 마지막의 [출처]와 대응한다. 별색·볼드는 강조다.
> ※ 일부 사회 통계([1]·[3])는 발표 전 최신 수치로 한 번 더 확인할 것.

---

## Ⅰ. 주제

### 1. 개발 배경 및 필요성

#### 자막은 "말"은 전하지만 "말투"는 전하지 못한다
우리가 대화에서 감정을 읽는 단서는 **단어가 아니라 말투**다. 심리학자 Mehrabian의 고전적 연구에 따르면, 사람이 **감정·태도**를 전달할 때 말의 *내용(언어)*이 차지하는 비중은 **7%**에 불과하고, **목소리의 톤·억양(운율)이 38%**, 표정이 55%를 차지한다. [2] 즉 *"무엇을 말했는가"*보다 *"어떻게 말했는가"*가 감정의 대부분을 결정한다.

그러나 영상의 **자막은 오직 단어(7%)만 전달**한다. 목소리에 담긴 38%의 감정 정보는 자막에서 완전히 사라진다.

#### 같은 "괜찮아", 네 개의 전혀 다른 뜻
예를 들어 드라마 속 **"괜찮아"** 한 마디는 말투에 따라 **① 진심 어린 위로, ② 비꼼(반어), ③ 억눌린 슬픔, ④ 참고 있는 분노**로 완전히 달라진다. 일반 자막은 이 네 가지를 모두 *똑같은 한 줄의 글자*로 보여 준다. 그 결과 청각장애인은 **대사(line)는 읽지만, 인물의 감정·연기(acting)는 놓치게 된다.** 농담과 진담, 진심과 비꼼의 구분이 사라지는 것이다.

#### 청각장애인에게 미디어 감정 접근권은 권리의 문제다
우리나라의 등록 청각장애인은 **약 40만 명 이상**에 이른다. [1] 이들에게 영상 미디어는 단순한 오락이 아니라 사회·문화에 참여하는 통로다. 그러나 현재의 자막은 *대사*만 전달할 뿐 *감정*을 전달하지 못해, 청각장애인은 비장애인과 **같은 영상을 보고도 다른 이야기를 이해**하게 된다. 따라서 자막에 **"감정"을 더하는 도구**는 편의가 아니라 **문화적 접근권**의 문제다.

### 2. 주제(목적)

#### 개발의 주제 및 목적
본 작품 **SoundShape**는 음성의 **운율(prosody)을 분석**하고 인공지능으로 **감정을 추출**한 뒤, 이를 **도형·색·크기·움직임의 시각 언어**로 변환하여 영상 위에 자막과 함께 보여 주는 시스템이다. 목적은 청각장애인이 *대사*와 *감정*을 **함께** 이해하도록 하는 것이며, 나아가 자폐 스펙트럼 등 감정 인식에 어려움을 겪는 이들로 확장하는 것이다.

#### 해결 방법
음성을 다음 단계로 처리한다.
1. **음성 인식(자막):** Whisper 모델로 발화를 글자와 단어 단위 시각으로 변환한다.
2. **감정 분석:** 각 발화 구간에서 **음향 운율(음높이·세기·떨림 등)을 PRAAT로 추출**하고, **딥러닝(wav2vec2)으로 감정을 분류**한다.
3. **시각 번역:** 추출한 감정을 **연구에 근거한 규칙**으로 도형·색·크기·움직임으로 바꾸어 영상 위에 자막과 동기화해 표시한다.

### 3. 유사 제품(연구) 및 차별점

#### 일반 폐쇄자막(Closed Caption)
대사를 글자로 보여 주고 `[음악]`·`[웃음]` 같은 소리 상황을 일부 괄호로 표기한다. 그러나 **화자의 감정 자체는 표현하지 못한다.** 비꼼처럼 *말과 뜻이 반대*인 경우를 전혀 구분할 수 없다.

#### 텍스트 감성분석 기반 이모지 자막
일부 서비스는 자막 *텍스트*를 감성분석해 이모지를 붙인다. 그러나 이는 **단어를 보고 감정을 추측**하므로, *"잘~한다"*처럼 긍정 단어로 비꼬는 경우 오히려 **반대로 표시**한다. 또한 감정을 몇 개의 고정된 이모지로 단순화한다.

#### 본 작품의 차별점 (5가지)
1. **운율 기반:** 텍스트가 아니라 *소리 자체*를 분석하므로 비꼼을 포착한다.
2. **연속 감정 공간:** Russell의 *정서가(valence)×각성(arousal)* 평면 [7] 을 사용한다. 6개 이산 라벨이 아니다.
3. **다채널 시각 언어:** 하나의 형태가 모양·색·크기·움직임으로 감정을 *동시에* 전달한다.
4. **연구 기반 매핑:** 모든 시각 규칙이 논문에 근거한다(Ⅱ-1).
5. **접근성 우선 설계:** 청각장애인을 주 사용자로 전제했다.

## Ⅱ. 작품 제작

### 1. 작품 설계

#### 설계 목표
(a) 음성 입력 → 시각 출력이 한 줄로 이어지는 **실제 작동하는 시스템**, (b) *"왜 분노가 빨강인가"*에 답하는 **과학적으로 방어 가능한 매핑**, (c) 직관적이고 **아름다운** 시각화, (d) **한국어 지원**.

#### 작동 원리 (전체 파이프라인)
```
음성/영상 → FFmpeg(16kHz 정규화) → Whisper(자막+단어 타임스탬프)
        → 발화 구간마다 ┌ PRAAT/Parselmouth : 운율 15종
                       └ wav2vec2 : 감정(범주형+차원형)
        → 보정·하이브리드·텍스트 보조·운율 변조·불확실성 처리
        → 연구 기반 매핑(감정→도형·색·크기·움직임)
        → WebGL 셰이더로 영상 위 시각화(자막과 동기화)
```

#### 감정→시각 매핑의 과학적 근거
시각 규칙이 *자의적이지 않음*이 본 작품의 핵심이다. 각 채널은 다음 연구에 근거한다.

| 채널 | 규칙 | 근거 |
|---|---|---|
| **도형** | 각진=위협, 둥근=따뜻 | Aronoff [4]; Bar & Neta [5](뇌 편도체); Köhler [12] |
| **색(색상)** | 분노=빨강 등 (범문화적) | Hupka [6] |
| **색(채도·명도)** | 채도∝각성, 명도∝정서가 | Valdez & Mehrabian [11] |
| **크기** | ∝각성, 저음=큼 | Russell [7]; Ohala [8](주파수 코드) |
| **움직임** | 빠르고 거친 움직임=분노/고각성 | Pollick [9]; Banse & Scherer [10](지터·시머) |

#### 구현상의 핵심 설계
- **단일 설정(config):** 모든 매핑 규칙을 하나의 JSON에 두고 백엔드(Python)·프론트엔드(TypeScript)가 *동일하게* 읽어, 두 구현의 출력이 **바이트 단위로 같음**을 자동 검증한다.
- **운율 직접 변조:** *측정된* 지터·시머가 시각의 떨림 진폭을, 강도가 크기를, 발화 속도가 움직임 속도를 직접 조절한다. → 모델이 같은 감정으로 분류한 두 음성도 *더 떨리거나 크면 다르게* 보인다.
- **불확실성 처리:** 모델의 확신이 낮으면 시각을 *채도↓·크기↓·움직임↓*으로 중립화해, 틀린 감정을 *확신에 차서* 보여 주지 않는다.

#### 작품 외형
- **웹 애플리케이션:** 파일/유튜브 링크 입력 → 분석 후 재생(감정 오버레이, 토글, 감정 타임라인).
- **크롬 확장 프로그램:** 실제 유튜브 영상 위에 감정 필드를 실시간 오버레이.

### 2. 작품 제작
- **백엔드:** Python 3.11, FastAPI, faster-whisper(large-v3-turbo), Parselmouth, transformers, scikit-learn.
- **프론트엔드:** Next.js + TypeScript + **WebGL 셰이더**(프랙탈 노이즈로 분위기적 에너지 필드를 만들고 감정별 실루엣에 가둠).
- **실시간 처리:** 침묵을 기준으로 음성을 분할하고 첫 구간을 짧게 처리해 **약 6초 만에 재생을 시작**, 이후를 *재생보다 앞서* 처리하여 **재생 중 지연을 0**으로 만든다.
- **한국어 대응:** Whisper 한국어 자막이 정확하며, 감정의 정서가 보조에 **한국어 텍스트 감성 모델**을 언어별로 라우팅한다.
- **품질 관리:** 자동화 테스트 **23개**로 핵심 로직과 실패 상황을 검증한다.

## Ⅲ. 작품 테스트

본 작품은 **세 가지 테스트**로 검증하였다. *"고장 나지 않는가(A) → 맞는가(B) → 쓸모 있는가(C)"* 의 순서로, 각 테스트마다 5개 항목을 기술한다.

### ◆ 테스트 A — 시스템 안정성 테스트
**1. 테스트 목적** — 시연·사용 중 비정상 입력(무음·손상 파일 등)에도 시스템이 멈추지 않고, 핵심 로직이 의도대로 동작함을 자동 보장한다.
**2. 테스트 방법** — *주체:* 개발자. *대상:* 시스템 내부 코드(매핑 엔진·운율/감정/분할 로직·파일 처리). *도구·활용법:* **`pytest`**로 23개 테스트를 한 번에 실행. ① 정확성(매핑 규칙, **Python·TS 결과 동일성**), ② 로직(운율·분할·감정 보정), ③ **실패 케이스**(무음·손상 파일·잘못된 구간).
**3. 예상 결과** — 전부 통과, 비정상 입력에도 무중단.
**4. 실제 결과** — **23개 전부 통과**(약 8초). 무음·손상·경계 입력 모두 정상 처리, **충돌 없음**.
**5. 결과 분석** — 예상대로. 실패 케이스 무중단으로 **시연 안정성**을, 백엔드·프론트 동일성으로 **환경 일관성**을 확보 → 소프트웨어 품질·견고성 입증.

### ◆ 테스트 B — 감정 인식 정확도 테스트
**1. 테스트 목적** — *"감정을 시각화한다"*의 전제인 **감정 인식 정확도**를 영어·한국어로 정량 측정한다.
**2. 테스트 방법** — *대상 데이터:* 영어 **RAVDESS**(배우 연기·정답 라벨), 한국어 **AIHub 「감정 분류를 위한 대화 음성」**(자연 대화, 평가자 5인 다수결 라벨). [13][14] *도구:* Parselmouth·wav2vec2·scikit-learn. *방법(두 조건):* ① **제로샷** — 배포 시스템(영어 학습 기성 모델) 그대로, ② **학습형** — wav2vec2 임베딩+PRAAT 운율→SVM 학습(영어 **화자독립 교차검증**, 한국어 층화 교차검증).
**3. 예상 결과** — 기성 모델 불완전, 운율은 각성에 강함, **한국어<영어**, **학습형>제로샷**.
**4. 실제 결과**

| | 제로샷(기성 모델) | 학습형 분류기 |
|---|---|---|
| **영어**(RAVDESS, 연기) | **55.0%** (4분류) | **79.8%** (4분류, 화자독립) / 74.2%(8분류) |
| **한국어**(AIHub, 자연 대화) | **17.5%** (7분류, 우연=14.3%) | **43.6%** (7분류) |

각성–정답 상관 **r = 0.73(강함)**, 정서가 **r = 0.42(약함)**. 학습은 **두 언어 모두 약 +25점** 향상.
**5. 결과 분석** — ① 한국어 제로샷 17.5%는 우연(14.3%)과 거의 같다 → *영어 학습 모델의 한계를 숫자로 입증*(정직성). ② 학습이 두 언어 공통 +25점 → *접근법의 언어 일반성*. ③ 각성은 신뢰(0.73)·정서가는 음향만으로 어려움(0.42, 분야 공통의 '정서가 문제') → 텍스트 보조 도입의 근거이며, 시각의 핵심(크기·채도·움직임)이 각성에 의존하므로 한국어에서도 의미가 유지된다.

### ◆ 테스트 C — 사용자 효과 테스트 (핵심)
**1. 테스트 목적** — **소리를 끈 상태**에서 *자막만* 볼 때와 *자막+SoundShape*를 볼 때의 **감정 인식 정확도를 직접 비교**한다.
**2. 테스트 방법** — *주체:* 개발자. *대상:* 참가자 **6인**(소리를 끈 정상 청각자는 청각장애 상황의 인정된 대체 방식이다). *도구:* 본 웹앱(SoundShape ON/OFF 토글)·분석 스크립트. *방법:* 8개 클립을 **조건 A(자막만)/B(자막+SoundShape)**로 **교차 균형** 제시, 각 클립 후 **감정 6지선다+확신도(1~5)** 응답, **대응표본 t검정**으로 검증.
**3. 예상 결과** — B>A, 특히 비꼼·억눌린 감정에서 차이 클 것.
**4. 실제 결과 (소리 끔, N=6)**

| 조건 | 감정 인식 정확도 |
|---|---|
| 자막만 (A) | **27%** |
| 자막 + SoundShape (B) | **73%** |
| **향상폭** | **+45%p** |

대응표본 t검정 **p = 0.016 (유의, p<0.05)**. **비꼼·억눌린 감정: 0% → 67%**. 확신도 3.3 → 3.5.
**5. 결과 분석** — 예상 적중·효과 큼(+45%p). 특히 **비꼼 0→67%**는 *"말투가 글자를 이긴다"*는 핵심 가설을 직접 입증하며, 통계적으로 유의하다. *한계:* N=6·정상청각 무음·동일 클립 양조건(추후 청각장애 당사자·대규모 표본으로 보완).

## Ⅳ. 해석 & 결론

### 1. 결론
SoundShape는 자막의 *"무엇을 말했는가"*에 *"어떻게 말했는가"*를 더하여, **소리 없는 상황에서 감정 이해 정확도를 27%→73%로 유의하게(p=0.016) 향상**시켰다. 특히 자막만으로는 전혀 읽지 못하던 **비꼼·억눌린 감정을 0%→67%**로 끌어올렸다.
- **실용성:** 청각장애인의 미디어 감정 접근권 개선을 사용자 실험으로 입증.
- **응용성:** 자폐 스펙트럼 등 감정 인식 보조, 실시간 유튜브 확장.
- **차별성:** 운율 기반·연속 감정·다채널·**연구 기반 매핑**·접근성 우선의 5가지를 모두 구현, 매핑이 자의적이지 않음(논문 인용+수정 가능 config).
- **정직성:** 한국어 감정 정확도가 아직 낮음, 정서가가 음향만으로 어려움, 표본이 적음을 *숨기지 않고 측정·명시*했다.
