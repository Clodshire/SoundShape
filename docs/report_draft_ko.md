# SoundShape — 음성의 감정을 시각 언어로 번역하는 청각장애인용 감정 자막 시스템
### (작품설명서 초안 · 서식 2)

---

## Ⅰ. 주제

### 1. 개발 배경 및 필요성

자막은 **"무엇을 말했는가(言)"는 전달하지만 "어떻게 말했는가(調)"는 전달하지 못한다.** 그런데 사람의 의사소통에서 의미의 상당 부분은 단어가 아니라 **말투(운율, prosody)** — 음높이, 세기, 떨림, 속도 — 에 담긴다.

예를 들어 "괜찮아"라는 똑같은 한 마디는 말투에 따라 **(1) 진심 어린 위로, (2) 비꼼(반어), (3) 억눌린 슬픔, (4) 참고 있는 분노**로 완전히 다른 뜻이 된다. 일반 자막은 이 네 가지를 모두 똑같은 한 줄의 글자로 뭉뚱그린다. 그 결과 청각장애인은 **대사(line)는 읽지만 연기(acting), 즉 감정은 놓치게 된다.** 영화의 반전, 인물의 진심, 농담과 진담의 구분이 사라지는 것이다.

청각장애인에게 미디어는 단순한 오락이 아니라 사회·문화에 참여하는 통로다. 따라서 자막에 **"감정"을 더하는 도구**는 단순 편의가 아니라 **문화적 접근권(cultural accessibility)**의 문제다.

### 2. 개발 주제(목적)

본 작품 **SoundShape**는 음성의 **운율을 분석**하고 딥러닝으로 **감정을 추출**한 뒤, 이를 **도형·색·크기·움직임의 시각 언어**로 변환하여 영상 위에 자막과 함께 실시간으로 보여 주는 시스템이다.

- **핵심 목적:** 청각장애인이 자막의 "대사"와 함께 화자의 "감정"까지 직관적으로 이해하도록 한다.
- **확장 가능성:** 감정 인식에 어려움을 겪는 **자폐 스펙트럼·실어증·사회불안** 등으로 동일 기술을 확장할 수 있다.

### 3. 유사 제품(연구) 및 차별점

| 구분 | 기존 방식 | SoundShape |
|---|---|---|
| 정보원 | 텍스트(글자) | **음성 신호(운율)** |
| 감정 표현 | 없음 / [음악]·[웃음] 표기 / 이모지 1개 | **연속적 감정 공간** |
| 채널 | 단일 | **도형+색+크기+움직임(4채널)** |
| 근거 | 자의적 | **논문 기반 매핑** |

차별점은 다음 **5가지**다.
1. **운율 기반(prosody-grounded)** — 텍스트 감성분석이 아니라 *소리 자체*를 분석하므로 비꼼처럼 말과 뜻이 반대인 경우도 잡아낸다.
2. **연속 감정 공간** — Russell(1980)의 정서가(valence)×각성(arousal) 평면을 사용한다. 6개 이산 라벨이 아니다.
3. **다채널 시각 언어** — 한 개의 빛나는 형태가 모양·색·크기·움직임으로 감정을 동시에 전달한다.
4. **연구 기반 매핑** — 모든 시각 규칙이 인용 논문에 근거한다(아래 Ⅱ-1).
5. **접근성 우선 설계** — 청각장애인을 주 사용자로 전제하고 설계했다.

## Ⅱ. 작품 제작

### 1. 작품 설계

**■ 설계 목표**
- (a) 음성 입력 → 시각 출력이 한 줄로 이어지는 **실제 작동하는 end-to-end 시스템**
- (b) 심사위원의 *"왜 분노가 빨강인가?"*에 답할 수 있는 **과학적으로 방어 가능한 매핑**
- (c) 5초 안에 무슨 도구인지 이해되는 **직관적이고 아름다운** 시각화
- (d) 한국어 지원

**■ 작동 원리 (파이프라인)**

```
음성/영상  →  FFmpeg(16kHz 단일 채널 정규화)
          →  Whisper(faster-whisper large-v3-turbo) : 자막 + 단어 단위 타임스탬프
          →  발화 구간마다  ┌ PRAAT/Parselmouth : 운율 특징(음높이·세기·지터·시머 등 15종)
                          └ wav2vec2 감정 분류 : 범주형 + 차원형(정서가·각성·우월성)
          →  보정 → 하이브리드 감정 결정 → 텍스트 보조 → 운율 변조 → 불확실성 처리
          →  연구 기반 매핑(감정 → 도형·색·크기·움직임)
          →  WebGL 셰이더로 영상 위에 시각화 오버레이(자막과 동기화)
```

**■ 감정 추출 모델**
- **범주형:** `wav2vec2-superb-er`(분노/기쁨/중립/슬픔)
- **차원형:** `audeering` 모델(정서가·각성·우월성 연속값)
- 차원형 출력의 **계통적 편향을 데이터 기반 보정**(RAVDESS에 대한 최소제곱 적합)하고, 범주형 모델이 약한 부분(예: 슬픔을 한 번도 예측 못함)을 차원형 V/A로 **보완하는 하이브리드** 방식으로 표시 감정을 결정한다.
- **한국어:** Whisper 자막은 정확하나 감정 모델은 영어 기반이므로, **한국어 텍스트 감성 모델(WhitePeak)**을 *불확실할 때만* 보조적으로 사용한다(말투가 분명히 부정적이면 무시 → 비꼼 보존).

**■ 연구 기반 매핑(요약)**

| 채널 | 규칙 | 근거 |
|---|---|---|
| 도형 | 각진=위협, 둥근=따뜻 | Aronoff 1992; Bar & Neta 2006(편도체); Bouba/Kiki |
| 색(색상) | 분노=빨강 등 | Hupka 1997(범문화적) |
| 색(채도/명도) | 채도∝각성, 명도∝정서가 | Valdez & Mehrabian 1994 |
| 크기 | ∝각성 | Russell 1980; Ohala 1994(주파수 코드: 저음=큼) |
| 움직임 | 빠르고 거친 움직임=분노/고각성 | Pollick 2001; Banse & Scherer 1996(지터·시머) |

**핵심 설계 특징:** 모든 매핑 규칙을 **하나의 JSON 설정 파일**에 두고, 백엔드(Python)와 프론트엔드(TypeScript)가 *동일한 규칙*을 읽는다(두 구현의 출력이 **바이트 단위로 동일함을 검증**). 또한 **측정된 운율(지터·시머·강도·속도)이 시각의 움직임·크기를 직접 변조**하므로, 모델이 같은 감정으로 분류한 두 음성도 더 떨리거나 크면 다르게 보인다 — 즉 시각이 **연속적이고 운율에 근거**한다.

**■ 작품 외형**
- **웹 애플리케이션:** 파일 업로드 또는 유튜브 링크 입력 → 짧은 분석 후 재생(자막+감정 오버레이, ON/OFF 토글, 감정 타임라인, 범례).
- **크롬 확장 프로그램:** 실제 유튜브 영상 위에 감정 필드를 실시간 오버레이.

### 2. 작품 제작

- **백엔드:** Python 3.11, FastAPI / faster-whisper / Parselmouth / transformers / scikit-learn.
- **프론트엔드:** Next.js 16 + TypeScript + **WebGL 셰이더**(도메인 워프 프랙탈 노이즈로 분위기적 에너지 필드를 생성하고, 감정마다 다른 부드러운 실루엣에 가둠 — OLED 배경화면 같은 미감).
- **스트리밍 처리:** 침묵 지점을 기준으로 음성을 분할하고, 첫 청크를 짧게(~10초) 처리해 **약 6초 만에 재생을 시작**한 뒤 나머지를 *재생보다 앞서* 처리하여 **재생 중 지연을 0으로** 만든다.
- **정확도 개선:** 보정+하이브리드+텍스트 보조+불확실성 중립화를 적용했고, 특징 기반 분류기를 별도로 학습했다.
- **품질 관리:** 23개의 자동화 테스트(pytest)로 핵심 로직과 실패 상황을 검증한다.

## Ⅲ. 작품 테스트

### 1. 테스트 목적

- **테스트 A(시스템 안정성):** 시스템이 안정적으로 작동하고 잘못된 입력에도 멈추지 않는가?
- **테스트 B(감정 인식 정확도):** 감정 분석이 *실제로* 얼마나 정확한가? (정량적 과학 검증)
- **테스트 C(핵심 가치):** 이 도구가 *실제로* 사람의 감정 이해를 향상시키는가?

### 2. 테스트 방법

- **A — 자동화 단위·실패 테스트:** pytest로 매핑 정확성, 운율·분할·감정 로직, 그리고 **실패 케이스(무음 파일, 손상된 파일, 잘못된 입력)**가 충돌 없이 처리되는지 검증.
- **B — 정확도 평가:**
  - 데이터: **영어 RAVDESS**(연기된 감정 음성, 정답 라벨), **한국어 AIHub '감정 분류를 위한 대화 음성'**(자연 대화, 평가자 5인 다수결 라벨).
  - **제로샷:** 배포된 시스템(영어 학습 기성 모델)을 그대로 적용 → 정확도/혼동행렬.
  - **학습형:** wav2vec2 임베딩 + PRAAT 운율 특징을 결합해 분류기를 학습. 영어는 **화자독립 교차검증**(테스트 화자를 학습에서 제외), 한국어는 층화 교차검증.
- **C — 무음 비교 사용자 실험:** 소리를 끈 상태(청각장애 상황 모사)에서 **참가자 6인**에게 8개 클립을 보여 주되, 절반은 **조건 A(자막만)**, 절반은 **조건 B(자막+SoundShape)**로 제시(클립별 조건을 form으로 교차 균형). 각 클립 후 **감정 6지선다 + 확신도(1~5)**를 응답받아, 정답 대비 정확도를 조건별로 비교하고 **대응표본 t검정**으로 유의성을 검증. 도구는 본 웹앱(SoundShape ON/OFF 토글)과 분석 스크립트.

### 3. 예상 결과

- **A:** 모든 테스트 통과, 오류 입력에도 무중단.
- **B:** 기성 모델은 언어·도메인 차이로 완벽하지 않을 것이며, 운율은 *각성* 축에 강할 것. 한국어는 영어보다 낮고, 학습형이 제로샷보다 높을 것.
- **C:** 자막+SoundShape가 자막만보다 감정 정확도가 높을 것이며, **특히 비꼼·억눌린 감정에서 차이가 클 것.**

### 4. 실제 결과

**■ A — 시스템 안정성**
- 자동화 테스트 **23개 전부 통과**(약 8초). 무음·손상 파일·경계 입력 모두 정상 처리되며 **충돌 없음.**

**■ B — 감정 인식 정확도**

| | 제로샷(기성 모델) | 학습형 분류기 |
|---|---|---|
| **영어**(RAVDESS, 연기) | **55.0%** (4클래스) | **79.8%** (4클래스, 화자독립) |
| **한국어**(AIHub, 자연 대화) | **17.5%** (7클래스, 우연=14.3%) | **43.6%** (7클래스) |

- 영어 운율–정답 상관: **각성 r = 0.73(강함)**, **정서가 r = 0.42(약함)**.
- 학습은 **두 언어 모두 약 +25점** 향상시켰다(영어 +25, 한국어 +26).

**■ C — 사용자 실험 (소리 끔, N=6)**

| 조건 | 감정 정확도 |
|---|---|
| 자막만 (A) | **27%** |
| 자막 + SoundShape (B) | **73%** |
| **향상** | **+45%p** |

- 대응표본 t검정 **p = 0.016 → 통계적으로 유의(p < 0.05).**
- **비꼼·억눌린 감정 클립: 0% → 67%.**
- 평균 확신도: 3.3 → 3.5.

### 5. 결과 분석

- **A:** 소프트웨어 품질과 견고성을 확보했다.
- **B:** (1) 영어 학습 기성 모델은 한국어 자연발화에서 **거의 우연 수준(17.5% ≈ 14.3%)** — '영어 모델'의 한계를 *정량적으로* 입증했다. (2) 학습이 두 언어에서 공통으로 +25점 → 접근법이 **언어에 일반화**됨을 보였다. (3) 각성은 신뢰할 수 있으나(0.73) **정서가는 음향만으로 어렵다(0.42)** — 이는 SER 분야 전반의 '정서가 문제'로, 우리가 텍스트 보조·보정을 도입한 이유다. **시각의 대부분(크기·채도·움직임)이 신뢰 가능한 각성에 의존**하므로 한국어에서도 시각의 의미는 유지된다.
- **C:** 예상대로였으나 **효과 크기가 컸다(+45%p)**. 특히 **비꼼 0→67%**는 *"말투가 텍스트를 이긴다"*는 본 작품의 핵심 가설을 직접 입증한다. 결과는 **통계적으로 유의(p=0.016)**하다.

## Ⅳ. 해석 & 결론

### 1. 결론

SoundShape는 자막의 *"무엇을 말했는가"*에 *"어떻게 말했는가"*를 더하여, **소리가 없는 상황에서 감정 이해 정확도를 27%에서 73%로 유의하게(p=0.016) 향상**시켰다. 특히 자막만으로는 전혀 읽지 못하던 **비꼼·억눌린 감정을 0%에서 67%로** 끌어올렸다.

- **실용성:** 청각장애인의 미디어 감정 접근권을 실제로 개선함을 사용자 실험으로 입증했다.
- **응용 가능성:** 동일 기술을 자폐 스펙트럼 등 감정 인식 보조로 확장할 수 있으며, 크롬 확장으로 실시간 유튜브에도 적용된다.
- **차별성:** 운율 기반·연속 감정·다채널·**연구 기반 매핑**·접근성 우선이라는 5가지 차별점을 모두 구현했고, 매핑이 자의적이지 않음(논문 인용 + 수정 가능한 config)을 보였다.
- **정직성:** 한국어 감정 정확도가 아직 낮다는 점, 정서가가 음향만으로 어렵다는 점, 표본이 적다는 점을 **숨기지 않고 측정·명시**했다 — 이는 과학적 성숙도의 증거다.

### 2. 추후 개선사항

1. **한국어 감정 모델 fine-tune** (AIHub·KEMDy 등으로) → 한국어 정확도 43.6% → 목표 60%+.
2. **정서가 보강:** 영상의 표정 인식을 더한 멀티모달, 한국어 텍스트 감성 강화.
3. **사용자 연구 확대:** 청각장애인 당사자 직접 참여, 표본 수 증가.
4. **화자 분리(다중 화자)·음악 대응** 추가.
5. **실시간 최적화**(경량 모델·온디바이스 추론).
