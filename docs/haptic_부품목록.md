## 조립

```
[맥북] ──USB-C── [1. ESP32-S3 Feather] ──Qwiic 케이블── [2. DA7280 햅틱]
```

Qwiic 케이블은 **양쪽에 플러그가 이미 달린 완제품 선**이다. 이어폰 잭처럼 딸깍 꽂으면 끝이고,
모양 때문에 한 방향으로만 들어가서 거꾸로 꽂을 수가 없다. 선 4가닥(전원·접지·데이터 2개)이
안에 다 들어 있다.

보드에 보이는 동그란 구멍들(GND, 3V3, SDA, SCL…)은 **굳이 납땜하고 싶은 사람용 예비**다.
우리는 손대지 않는다.

| 보드 | Qwiic 소켓 | 확인 출처 |
|---|---|---|
| Adafruit ESP32-S3 Feather | 1개 (JST-SH 4핀) | Adafruit 공식 핀아웃 |
| SparkFun DA7280 햅틱 | **2개** (하나만 쓰면 됨) | SparkFun 공식 후크업 가이드 |
