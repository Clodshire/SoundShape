# 포스터 발표 5분 대본

> 최종 포스터(2장) 기준. **왼쪽 = 가리킬 곳 / 오른쪽 = 할 말.**
> 굵은 글씨만 외우셔도 됩니다. 숫자는 포스터에 적힌 것과 같습니다.

```
0:00  여는 말 + ① 무엇인가        30초
0:30  ② 왜 필요한가              60초
1:30  ③ 어떻게 작동하는가         60초
2:30  ④ 기존과 무엇이 다른가      40초
3:10  ⑤ 검증                    80초
4:30  ⑥ 개선 + 마무리            30초
```

# 0:30 · ② 왜 필요한가 (60초)

| 가리킬 곳 | 할 말 |
|---|---|
| "잘~한다." | "글자만 보면 **칭찬**입니다. 말투를 들으면 **비꼼**입니다." |
| | "비꼼은 **단어가 아니라 낮아진 음높이 같은 운율에 실립니다.** 그래서 글자를 아무리 들여다봐도 안 보입니다." |
| **38% vs 7%** | "말과 어조가 어긋날 때 사람은 **어조에 38%, 말의 내용에는 7%** 의존합니다. 자막은 그 **7%만** 전달하고 있습니다." |
| **10% 이하** | "실제로 저희 실험에서 **자막만 보고 비꼼을 맞힌 비율이 10% 이하**였습니다. 청인은 **0%**, 청각장애인은 **10%**." |
| **4.3억 명 / 44만 명** | "전 세계 **4억 3천만 명**, 국내 등록 청각장애인 **44만 명**입니다." |
| 인용 두 개 | "실험에 참여하신 분이 하신 말입니다. **'표정 없이 자막만 보이면 무슨 상황인지 알기 어렵다.'**" |
| 오른쪽 아래 박스 | "그리고 **청각장애인만의 문제가 아닙니다.** 아동, 자폐 스펙트럼, 지하철에서 소리를 끄고 보는 사람도 같습니다." |

> 💡 **이 막의 핵심은 38% vs 7% 입니다.** 자막이 왜 부족한지를 한 쌍의 숫자로 끝냅니다.

# 2:30 · ④ 기존과 무엇이 다른가 (40초)

**포스터 2장으로 넘어갑니다.**

| 가리킬 곳 | 할 말 |
|---|---|
| 표의 위 네 줄 | "기존 자막은 **감정을 아예 못 전하거나**, 이모지처럼 **사람이 일일이 붙여야** 하거나, 글자 자체를 바꾸는 방식입니다." |
| Caption with Intention | "이건 칸 광고제 수상작인데, 글자에 색과 움직임을 줍니다. 다만 **수작업**이고 자막 자체가 읽기 어려워집니다." |
| SoundShape 줄 | "저희는 **글자가 아니라 소리를 분석**합니다. 그래서 **자동**이고, 비꼼처럼 말과 뜻이 반대인 경우를 잡습니다." |
| 단점 칸 | "**단점도 적었습니다.** 도형이 화면을 일부 가립니다." |

> 💡 **단점 칸을 직접 짚으십시오.** 심사위원이 찾아내기 전에 먼저 말하는 편이 훨씬 낫습니다.

# 3:10 · ⑤ 검증 (80초)

| 가리킬 곳 | 할 말 |
|---|---|
| 실험 방식 | "감정을 알기 어려운 영상을 **한 번은 자막만, 한 번은 도형까지** 보여 주고 정확도를 비교했습니다." |
| 1차 / 2차 | "1차는 청인 6명이 **소리를 끄고** 참여한 모사 실험이었고, 2차는 **청각장애인 10명**입니다. 서울시농아인협회 지원으로 서초구·노원구 수어통역센터에서 진행했습니다." |
| 사진 | "수어 통역사와 함께 진행했고, 연구 참가 동의서를 받았습니다." |
| **112 / 112** | "먼저 **안정적으로 작동하는가.** 자동화 테스트 112개가 전부 통과했고, 무음이나 손상된 파일에도 멈추지 않습니다." |
| **96% 수준** | "**감정을 읽어 내는가.** 소리를 들으며 자막을 보는 사람 대비 **96% 수준**입니다." |
| ③ 막대 그래프 | "**소리 없이도 감정이 전달되는가.** 청인은 27%에서 **73%**, 청각장애인은 23%에서 **45%** 로 올랐습니다." |
| ④ 막대 그래프 | "**비꼼도 읽히는가.** 청인은 0%에서 **67%**, 청각장애인은 10%에서 **40%** 입니다." |
| | "**자막만 봤을 때는 비꼼을 거의 아무도 못 읽었습니다.**" |
| 인용 | "참여하신 분 말입니다. **'도형을 반복해서 보니 모양과 색깔이 어떤 감정인지 자연스럽게 이해되었어요.'**" |

> 💡 **두 집단의 숫자가 다른 것을 먼저 말하십시오.** "청인 46%p, 당사자 22%p" 를 숨기면 질문으로 돌아옵니다.
>
> **질문 대비**: "왜 당사자 쪽이 낮습니까?" → *"조건이 다릅니다. 1차는 보기가 6개였고 개별로 진행했으며, 2차는 보기가 5개에 집단으로 한 번만 설명을 듣고 진행했습니다. **실제 사용자에게서 나온 22%p가 더 보수적이고 믿을 수 있는 숫자**라고 봅니다."*
