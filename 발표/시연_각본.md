> **백업**: 유튜브 확장이 실패할 때를 대비해 `poster/` 폴더의 그림과

### 질문 카드에 대해 — 이 한 단계는 직접 확인하십시오

`ko_test.wav`의 첫 구간은 **확신도 43%** 로 기준(45%)보다 낮아서 조건은 확실히 맞습니다.
업로드가 되면 오른쪽 확신도도 43%로 바뀌는 것까지 확인했습니다. 다만 **카드가 실제로
화면에 뜨는 순간까지는 검증하지 못했습니다** — 클립이 5초로 짧습니다.

**발표 전에 이 순서로 한 번만 돌려 보십시오.**

1. 새로고침 → `ko_test.wav` 업로드 → 동의 카드에서 **참여하기**
2. `처음부터` 누르고 끝까지 재생
3. 카드가 뜨면 ✅ — 각본 그대로 진행
4. 안 뜨면 아래 둘 중 하나

**안 뜰 때 ①  리허설용 테스트 모드** (연습에만 쓰고 발표 땐 끄십시오)

```bash
python scripts/feedback_test_mode.py on    # 거의 모든 구간에서 뜸
python scripts/feedback_test_mode.py off   # 발표 직전 반드시 원복
```

> 켠 채로 발표하면 "원래 이렇게 자주 뜨느냐"는 질문에 잘못된 인상을 줍니다.
> **연습은 켜고, 발표는 끄십시오.**

**안 뜰 때 ②  그냥 말로 넘기기** — 카드 대신 확신도 막대를 가리키며
"이렇게 확신이 낮은 구간에서만 짧게 되묻습니다" 한 줄로 끝내도 충분합니다.

> 💡 **알아두면 좋은 것**: 카드는 한 번 뜨면 **2분간 다시 안 뜹니다.** 그런데 이 간격은
> 메모리에만 있어서 **새로고침하면 초기화**됩니다. 리허설에서 한 번 봤더라도
> 발표 직전에 새로고침하면 다시 뜰 수 있습니다.

```

3막  범례 ON → 맞춤 설정 → 지구본 → 키보드

      (실패하면 30초 안에 슬라이드로)

5막  화자 구분·햅틱 정직하게
```
