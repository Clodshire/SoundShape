# 현장 시연 계획

심사위원이 **내 화면을 본다**는 것과 **행사장 와이파이가 나쁘다**는 것, 두 가지를
전제로 짰습니다. 둘 다 이 계획의 설계 조건이지 주의사항이 아닙니다.

---

# 먼저 알아야 할 숫자

직접 재 봤습니다. 이걸 모르면 무대에서 사고가 납니다.

| | 걸리는 시간 |
|---|---|
| 서버 두 개 뜨는 데 (모델 예열 포함) | **14초** |
| 34초짜리 드라마를 **현장에서 분석** — 첫 구간 | **19.7초** |
| 같은 영상 — 분석 끝까지 | **51.2초** |
| 대본 재생 (`?script=`) | **0초** |

**현장에서 영상을 올리면 화면이 30초쯤 멈춥니다.** 심사위원 앞에서 30초는
아주 깁니다. 그래서 아래 계획은 그 30초를 **설명 시간으로 바꿉니다.**

그리고 중요한 사실 하나 — **웹사이트 시연은 인터넷이 하나도 필요 없습니다.**
전부 노트북 안에서 돕니다. 와이파이가 위협하는 건 **크롬 확장(유튜브)뿐**입니다.

---

# 시작 10분 전

바탕화면의 **`시연_시작.command` 를 더블클릭**하면 끝납니다.

서버 두 개를 띄우고, 모델을 미리 데우고, 크롬 탭 세 개를 열어 줍니다.
허깅페이스에 나가지 않도록 오프라인 모드로 뜨기 때문에 와이파이가 죽어 있어도 됩니다.

"준비 완료" 가 뜨면 **터미널을 ⌘H 로 숨기십시오.**

## 화면에서 치워야 할 것

| 할 것 | 왜 |
|---|---|
| **Claude Code · VS Code · 터미널 종료 또는 ⌘H** | 보이면 안 됩니다 |
| **집중 모드(Do Not Disturb) 켜기** | 카톡 알림이 발표 중에 뜹니다. 제일 흔한 사고입니다 |
| **독 자동 숨기기** — 시스템 설정 → 데스크탑 및 Dock | 아이콘 줄이 화면 아래 남습니다 |
| **크롬 새 창 하나만** 쓰고 다른 창은 모두 닫기 | ⌘Tab 을 누를 일이 없어집니다 |
| **북마크 막대 숨기기** ⇧⌘B | 개인 북마크가 보입니다 |
| **전체화면** ⌃⌘F | 메뉴 막대까지 사라집니다 |

**시연 중에는 ⌘Tab 을 쓰지 마십시오.** 탭 이동은 **⌘1 ⌘2 ⌘3** 으로만.
크롬 한 창 안에서만 움직이면 다른 건 절대 안 보입니다.

# 시연 (약 4분)

## ① 문제를 먼저 보여 준다 — 40초

**⌘2** (데모 1 · 변호사 장면). 먼저 **"자막만 보기"** 를 눌러 두고 재생합니다.

> 이 장면을 소리 없이 보시면, 자막은 다 읽히는데 **이 사람이 지금 화가 났는지
> 비꼬는 건지는 안 보입니다.**

다 보고 나서 **"자막 + SoundShape"** 로 바꿔 같은 장면을 다시 재생합니다.

> 같은 영상입니다. 바뀐 건 도형 하나뿐입니다.

**토글 하나로 전후를 보여 주는 것**이 이 시연의 핵심입니다. 두 번 재생하는 10초가
포스터의 모든 그래프보다 강합니다.

## ② 한 영상 안에서 감정이 바뀐다 — 40초

**⌘3** (데모 2 · 저금통 장면). 그냥 끝까지 재생합니다. 17초쯤에서 멈추고:

> 저금통이 없어진 걸 **경찰 보고서처럼** 읊고 있습니다. "있지 아니하고", "모습을
> 드러내지 않고 있어", "이 사건과 관련이 있을까?" — 말은 딱딱한데 **얼굴은 아무것도
> 안 알려 줍니다.** 그 어긋남을 도형이 비꼼으로 잡아냅니다.

여기서 심사위원이 가장 많이 끄덕입니다. **이 장면을 서두르지 마십시오.**

## ③ 진짜로 도는 걸 보여 준다 — 60초

**⌘1** (소개 페이지) → **"파일 선택하기"** → `demo2.mp4`

누르는 즉시 "영상을 분석하고 있어요…" 가 뜹니다. **여기서 기다리지 말고 바로
말을 시작하십시오.** 분석이 도는 30초가 설명 시간입니다.

> 지금 하고 있는 게 이겁니다. 먼저 목소리와 배경음을 분리하고, 말이 끊기는 곳마다
> 잘라서, 각 구간의 음높이·세기·떨림·말 속도를 **잽니다.** 추측이 아니라 측정입니다.
> 그다음 그 숫자를 저희가 학습시킨 분류기에 넣어서 감정을 정합니다.
> 지금 화면에 올라가는 퍼센트가 분석이 끝난 비율입니다.

말이 끝날 때쯤 재생이 시작됩니다.

> **방금 이건 미리 만들어 둔 게 아니라 지금 분석한 결과입니다.**

이 한 문장을 꼭 하십시오. 앞의 ①②가 매끄러웠던 만큼, 이게 진짜라는 증거가 필요합니다.

## ④ 유튜브에서도 된다 — 40초 〔와이파이 되면〕

크롬 확장을 켜 둔 탭으로 가서 유튜브 영상에 **+SoundShape** 를 누릅니다.

**와이파이가 안 되면 시도하지 마십시오.** 바로 ⑤로 넘어가십시오.

## ⑤ 마무리 — 20초

> 자막은 **무엇을** 말했는지를 전합니다. SoundShape는 **어떻게** 말했는지를 전합니다.

---

# 솔직하게 말해야 하는 것

①②는 **감정과 확신도를 저희가 지정해 둔 대본 재생**입니다. 짧은 발화에서는
모델이 흔들려서, 화면을 설명하려면 값을 고정해야 했습니다.

**먼저 말하지는 않되, 물으면 숨기지 마십시오.**

> 앞의 두 개는 **화면을 설명하려고 감정을 지정해 둔 예시**입니다. 방금 ③에서
> 돌린 게 모델이 실제로 낸 결과고요. 성능 숫자는 교차검증으로 **영어 79.8%,
> 한국어 49.6%** 입니다.

③을 반드시 넣는 이유가 이것입니다. **③이 있으면 ①②가 연출이어도 문제가 되지
않습니다. ③이 없으면 전부 의심받습니다.**

---

# 안 될 때

| 무슨 일 | 어떻게 |
|---|---|
| **와이파이 죽음** | ①②③ 은 전부 로컬입니다. 그대로 진행하고 ④만 건너뜁니다 |
| **분석 서버가 안 떴다** | ①② 는 분석 서버 없이도 됩니다. ③ 대신 "서버 문제로 지금은 대본으로 보여드리겠습니다" 하고 ④로 |
| **③이 1분 넘게 안 끝남** | "분석이 오래 걸리네요" 하고 ⌘2 로 돌아가 이어서 설명. 멈춰 서서 기다리지 마십시오 |
| **크롬 확장이 안 먹음** | 유튜브 탭 **새로고침**. 그래도 안 되면 포기하고 영상 재생 |
| **전부 안 됨** | `SoundShape_데모_45초.mp4` 를 전체화면으로 재생. 43초 안에 다 들어 있습니다 |

**영상 파일은 바탕화면과 USB 양쪽에 두십시오.** 클라우드에 두지 마십시오.

# 체크리스트 (인쇄해서 들고 가십시오)

```
□ 노트북 충전 100% + 충전기
□ 기기 소리 켜짐 확인 (③ 에서 대사가 들려야 설득력이 삽니다)
□ 집중 모드 ON
□ Claude Code / VS Code / 터미널 종료
□ 독 자동 숨기기
□ 크롬 한 창, 탭 3개, 북마크 막대 숨김
□ 시연_시작.command 실행 → "준비 완료" 확인
□ ⌘2 한 번 재생해 보기 (도형이 뜨는지)
□ 터미널 ⌘H
□ USB 에 SoundShape_데모_45초.mp4
□ 휴대폰 핫스팟 켤 준비 (④ 용)
```

마지막 줄이 중요합니다. **행사장 와이파이 대신 휴대폰 핫스팟**을 쓰면 ④가 살아날
수 있습니다. 미리 노트북에 연결해 두고 비밀번호를 외워 두십시오.
