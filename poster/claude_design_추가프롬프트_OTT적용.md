이미 만든 포스터를 **부분만** 고치는 지시입니다. 밴드 높이·칸 나눔은 그대로 두세요.

## ① 산점도 그림 교체 (필수)

**증상**: 포스터 2 · B밴드(④ 하이브리드 렌더링)의 각성/정서가 산점도에서
x축 라벨("정서가 r=0.42")이 그래프 테두리와 겹쳐 보였습니다.

**원인과 해결**: 라벨 자체가 아니라 축 아래 여백이 라벨 한 줄 높이보다
좁았던 것입니다. `scripts/poster/make_va_scatter_ko.py` 로 여백을 다시 잡아
`figures/va_scatter_ko.png` 를 새로 만들어 뒀습니다. 데이터는 원본과
**완전히 같습니다** (RAVDESS actors 01·02 · n=120 · valence r=0.42 · arousal r=0.73 ·
재실행으로 재현 확인 완료).

**첨부**: `figures/va_scatter_ko.png`

**붙여넣을 프롬프트**:
```
포스터 2의 B밴드(④ 하이브리드 렌더링) 안에 있는 각성/정서가 산점도를
첨부한 figures/va_scatter_ko.png 로 교체해 줘. 그 칸의 크기·위치는 그대로 두고
그림만 바꿔. 이 그림은 이미 완성된 이미지이니 다시 그리지 말고 그대로 배치해 줘.
```

## ② 실제 상영관·OTT 적용 경로 (F밴드에 추가)

**왜 넣는가**: 작품 코드 자체를 특정 OTT·상영관에 맞춰 바꾸는 것은 방향이
아닙니다. 고등학생 대회 시제품이 저작권·배급·설치 승인 같은 행정 절차까지
통과한 경우는 거의 없고, 이건 개발이나 창의력의 문제가 아니기 때문입니다.
대신 **적용 경로를 구체적으로 언급하는 것으로 충분**합니다 — "향후
상용화하겠다"처럼 두루뭉술하게 두지 않고, 실제로 어떻게 적용될 수 있는지
두 가지 경로를 짧게 답합니다.

F밴드(한계·결론·참고문헌)의 **F2 결론 + 향후 과제** 안에, 기존 5개 항목을
줄이지 않고 **6번째 항목으로 한 줄만** 추가하면 됩니다.

**붙여넣을 프롬프트**:
```
포스터 2의 F밴드 F2(결론 + 향후 과제) 안에서만 고쳐 줘. 다른 밴드는 건드리지 마.
향후 과제 목록 맨 끝에 여섯 번째 항목을 한 줄로 추가해 줘. 기존 5개 항목의
글자 크기·줄 수는 그대로 두고, 이 항목도 같은 스타일의 한 줄로:

"실제 적용 경로 — 극장은 스마트글래스형 개인 기기에 앱으로 설치, OTT는
자막 on/off 같은 재생 옵션으로 무료 제공"

F밴드 전체 높이(530px)는 바꾸지 마. 줄이 넘치면 이 항목의 글자만 살짝 줄여.
```
