# PowerPoint 로 내보내기 (편집이 꼭 필요할 때만)


`.dc.html` 을 **A0 슬라이드 한 장**짜리 `.pptx` 로 바꾼다.
모든 글자가 진짜 텍스트 상자, 모든 카드가 진짜 도형이 되므로 파워포인트에서
위치·크기·문구를 자유롭게 고칠 수 있다.

## 1단계 — 레이아웃 뽑기 (크롬)

**파일을 따로 받을 필요가 없다.** 브라우저에 이미 그려진 화면을 읽으므로,
포스터가 보이는 상태이기만 하면 된다. 이미지도 JSON 안에 함께 담긴다.

1. 포스터를 **크롬에서** 연다 (Claude Design 편집기 화면 그대로도 된다).
2. `F12` → **Console** 탭.
3. `scripts/poster/extract.js` 전체를 복사해 붙여넣고 Enter.
4. 아트보드가 어느 요소인지 먼저 찾는다.

```
findPosterRoots()
```

크기와 비율이 붙은 후보 목록이 나온다. **A0 세로면 비율이 1.414 근처**다.

```
0: 2384×3370  비율 1.414  <div.artboard>  자식 42개
1: 1920×1080  비율 0.563  <div.editor>    자식 8개
```

5. 맞는 번호로 추출한다.

```
downloadPosterLayout(0)
```

`layout.json` 이 다운로드된다. 이 파일 하나만 있으면 된다.

> **편집기 확대/축소는 자동 보정된다.** 아트보드가 35% 로 축소돼 보이고 있어도
> 좌표와 글자 크기를 원래 값으로 되돌려 뽑는다 (검증 완료).
>
> **iframe 안에 있어도 찾는다.** 단 다른 도메인의 iframe 은 브라우저가 막으므로
> 후보에 안 나온다. 그럴 땐 그 iframe 을 새 탭에서 직접 연 뒤 다시 실행한다.
>
> 렌더된 DOM 의 **계산된 좌표**를 읽으므로, flex 든 grid 든 절대배치든
> 어떤 방식으로 만들었어도 위치가 정확히 나온다.

## 2단계 — PPTX 만들기

```bash
/Users/birdhouse/.soundshape_venv/bin/python scripts/poster/build_pptx.py ~/Downloads/layout.json poster/SoundShape_포스터.pptx --paper a0
```

`--paper` 는 `a0` `a1` `a2`. 캔버스가 가로로 길면 종이도 자동으로 가로가 된다.

## 옮겨지는 것 / 안 옮겨지는 것

| | 결과 |
|---|---|
| 글자 (내용·크기·굵기·색·정렬·자간·줄간격) | ✅ 진짜 텍스트 상자 |
| 카드·박스 (배경색·테두리·둥근 모서리·점선) | ✅ 진짜 도형 |
| 반투명 배경 | ✅ 투명도까지 |
| 이미지 (PNG·JPG) | ✅ 그대로 |
| SVG | ✅ 3배 해상도 PNG 로 변환해 삽입 |
| **그라디언트** | ⚠️ **첫 색으로 단색 근사** — 실행 후 목록으로 알려 줌 |
| **그림자** | ⚠️ **생략** — 실행 후 목록으로 알려 줌 |

변환이 끝나면 손봐야 할 곳이 좌표와 함께 출력된다. 그 몇 군데만 파워포인트에서
직접 채우면 된다.

## 폰트

**포스터에 쓴 글꼴이 파워포인트를 여는 컴퓨터에 설치돼 있어야 한다.**
한글 글꼴은 동아시아 슬롯에도 같은 이름을 넣어 두었으므로, 설치만 돼 있으면
라틴 글꼴로 대체되지 않는다. 인쇄소에 넘길 때는 **PDF 로 내보내는 것이 안전하다.**

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 글자가 상자 밖으로 넘침 | 파워포인트 줄바꿈이 브라우저와 미세하게 다름 — 상자를 조금 넓히면 됨 |
| 글꼴이 다르게 보임 | 그 글꼴이 안 깔려 있음 |
| 그림이 빠짐 | 이미지가 다른 도메인에 있어 읽지 못한 경우. 실행 로그에 남는다 |

# 📄 PDF 로 내보내기 (권장)

```bash
/Users/birdhouse/.soundshape_venv/bin/python scripts/poster/html_to_pdf.py \
  "입력.html" "출력.pdf" --paper a0 [--landscape] [--wait 20000]
```

## 왜 크롬 인쇄 대화상자로는 안 되나

크롬 인쇄 창에는 **A0 용지가 없다.** `@page { size: 841mm 1189mm }` 를 CSS 에
넣어도 명령줄 `--print-to-pdf` 는 무조건 레터(216×279mm)로 고정해 버린다.
그래서 이 스크립트는 크롬을 디버깅 모드로 띄워 **DevTools 프로토콜의
`Page.printToPDF` 를 직접 호출**하고, 용지 크기를 인치로 지정한다.

## 자동으로 처리되는 것

| 문제 | 처리 |
|---|---|
| 아트보드가 가로로 나란히 있어 첫 장만 인쇄됨 | 종이 비율과 맞는 요소를 찾아 **세로로 쌓고 페이지를 끊는다** |
| 로딩 오버레이·썸네일이 남아 내용이 아래로 밀림 | 본문을 아트보드로 **통째로 교체** |
| 브라우저는 96dpi, PDF 는 72dpi 라 4/3 만큼 작게 나옴 | 아트보드 실제 폭을 재서 **배율을 자동 계산** (2384px → A0 면 1.3333) |

## 인쇄소에 넘길 때

**PDF 가 PPTX 보다 안전하다.** 글꼴이 파일 안에 들어 있어서 인쇄소 컴퓨터에
그 글꼴이 없어도 그대로 나온다. PPTX 는 글꼴이 없으면 대체돼서 줄바꿈이 밀린다.

**딱 하나 해상도 제약**: 포스터 안에 넣은 **사진·PNG 는 원본 해상도가 그대로**다.
글자와 도형은 벡터라 무한 확대되지만, 래스터 이미지는 아니다. A0 인쇄에서
선명하려면 넣을 이미지가 **긴 변 기준 2000px 이상**인 게 좋다.
