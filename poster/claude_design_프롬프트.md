기능을 다 설명하고 나서 실험을 몰아서 보여 주지 마.
**기능 하나 = 블록 하나**이고, 그 블록 안에 설명과 결과가 같이 들어간다.

각 기능 블록은 항상 이 4칸 구조를 반복한다 (12단 기준):

┌──────────────────────────────────────────────────────────┐
│ [파이프라인 배지]  ⑤ 기능 이름            ← 헤더 (높이 90px)  │
├────────────┬────────────┬────────────────────────────────┤
│ 어떻게      │ 그림/       │ 결과                            │
│ 작동하는가   │ 스크린샷    │ (표 또는 수치 2~3개)              │
│  4단        │  4단       │  4단                            │
└────────────┴────────────┴────────────────────────────────┘

**파이프라인 배지**: 각 블록 헤더 왼쪽에, 첨부한 그림1 파이프라인을
아주 작게(높이 60px) 줄여 넣고 **지금 설명 중인 단계만 강조색**으로
칠해 줘. 심사위원이 "이 기능이 시스템 어디에 있는지" 를 바로 알 수 있게.
7개 블록 전부에 넣되, 강조되는 단계만 달라진다.

**기능 순서는 파이프라인 흐름과 같다. 바꾸지 마.**
  ① 음원 분리      (입력 직후)

  ③ 화자 전환 감지  (분석, ②와 병렬)

■ 숫자 표현 — 지난 시안이 너무 과했다
════════════════════════════════════════════
연구 포스터답게. 광고 배너처럼 보이면 안 된다.

- **어떤 숫자도 60px 를 넘기지 마.** (예외: 포스터 번호 "1" "2")
- 핵심 수치는 본문(28px)의 1.3~1.4배 = **36~40px, 굵게, 강조색**
- 변화는 표 안에서 `27% → 73%` 형태로 쓰고 **도착값만** 강조색
- p값·n·CI 는 본문 크기(24~26px) 회색으로 수치 옆에 붙여 줘
- 크기 대신 **옅은 틴트 배경 띠**로 결과 행을 구분해 줘
- 숫자를 카드 한복판에 홀로 크게 띄우지 마. 항상 표나 문장 안에.
